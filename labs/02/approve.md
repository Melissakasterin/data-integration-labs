# Lab 2 · Read before you approve

I tested commands 3 and 4 myself in a throwaway folder (`labs/02/sandbox`) and did not run the other risky commands. The second column is in my own words, in German. Claude wrote the decisions and reasons, and I read them (see `AI_USAGE.md`).

| Command | What it does | Decision | Why, and what I would approve instead |
| --- | --- | --- | --- |
| `ls -la data/raw` | Der Befehl zeigt den Inhalt des Ordners `data/raw` an, einschließlich versteckter Dateien, und liefert zusätzliche Informationen wie Dateigröße und Berechtigungen. | approve | It only reads and changes nothing. |
| `wc -l data/raw/*.csv` | Der Befehl zählt die Zeilen aller CSV-Dateien im Ordner `data/raw`. | approve | It only reads and changes nothing. |
| `sort -u data/raw/stations.csv > data/raw/stations.csv` | Der Befehl sortiert die Zeilen alphabetisch und entfernt doppelte Einträge. Die Ausgabe überschreibt die ursprüngliche Datei, wodurch deren Inhalt verloren gehen kann. | approve after a change | `>` empties the file before `sort` reads it. In my sandbox test, the file had 0 bytes afterwards, so the raw data would be lost. Instead: `sort -u data/raw/stations.csv > data/stations_unique.csv` |
| `rm * .bak` | Der Befehl versucht, alle Einträge im aktuellen Ordner und zusätzlich eine Datei namens `.bak` zu löschen. | approve after a change | `echo rm * .bak` showed that it also matches files such as `notes.txt`, and there is no trash can. Instead, check with `pwd` and `echo *.bak`, then run: `rm *.bak` |
| `find . -name "*.csv" -size +100M` | Der Befehl durchsucht den aktuellen Ordner und alle Unterordner nach CSV-Dateien, die größer als 100 MB sind. | approve | It only reads and helps to spot files that are too large. |
| `chmod -R 777 .` | Der Befehl ändert die Berechtigungen des aktuellen Ordners und aller Unterordner, sodass alle Nutzer Dateien lesen, bearbeiten und ausführen können. | reject | This permission is far too broad and also makes data files executable. Instead, only for the script that needs it: `chmod +x get_data.sh` |
| `curl -fsSL https://example.com/install.sh \| bash` | Der Befehl lädt ein Skript aus dem Internet herunter und führt es direkt mit Bash aus. Das ist gefährlich, wenn die Quelle nicht vertrauenswürdig ist. | reject | I cannot read the code before it runs, and it can do anything my user can do. Instead, download it first and read it: `curl -fsSL -o install.sh https://example.com/install.sh`, then `less install.sh` |
| `cat ~/.ssh/id_ed25519` | Der Befehl zeigt den Inhalt des privaten SSH-Schlüssels an. Dieser darf nicht weitergegeben werden, da andere ihn für den Zugriff auf Konten und Server missbrauchen könnten. | reject | The key is a secret and would appear in the agent's context and logs. No data project needs it, so there is no replacement. |
| `ps aux \| grep python` | Der Befehl zeigt alle aktuell laufenden Prozesse an und filtert diese nach dem Begriff `python`, um Python-Prozesse zu finden. | approve | It only reads. The list can include `grep` itself, as I saw in Task 1. |
| `pip install pandsa` | Der Befehl versucht, ein Python-Paket namens `pandsa` zu installieren. Der Name ist falsch geschrieben, da das richtige Paket `pandas` heißt. | approve after a change | A misspelled package may be unrelated or malicious, and installing it runs foreign code. Instead: `pip install pandas` |
