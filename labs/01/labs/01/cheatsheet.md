# Markdown Cheatsheet

## 1. Headings

Use `#` for a main heading, `##` for a second-level heading, and `###` for a third-level heading.

## 2. Text Formatting

- **Bold text:** `**bold text**`
- *Italic text:* `*italic text*`
- ~~Strikethrough:~~ `~~strikethrough~~`

## 3. Lists

Unordered list:

- First item
- Second item
- Third item

Ordered list:

1. First step
2. Second step
3. Third step

## 4. Links and Images

Link: `[GitHub](https://github.com)`

Image: `![Alternative text](image-url)`

## 5. Code

Inline code: ` `print("Hello World")` `

Code block:

```python
print("Hello World")
```
