
# Open-Source Project Analysis: pandas

## 1. Project Overview

- **Project:** pandas
- **GitHub repository:** https://github.com/pandas-dev/pandas
- **Purpose:** pandas is a Python library for data manipulation and analysis.

## 3. Community Files

The pandas project provides several community files:

- **Code of Conduct:** Defines expectations for respectful and inclusive behavior.
- **Contributing Guide:** Explains how to report bugs and submit contributions.
- **Security Policy:** Provides guidance for reporting security vulnerabilities.

These files help contributors understand the project's rules and how to participate responsibly.

## 4. Contributors and Maintainers

- **Contributors:** The pandas repository has many contributors who submit code, bug fixes, tests and documentation improvements.
- **Maintainers:** The project has triage members and core team members with different permissions.
- **Who can merge pull requests?** Only core team members can merge pull requests.
- **Source:** [pandas Maintenance Guide](https://pandas.pydata.org/docs/dev/development/maintaining.html)

## 5. Funding

- **Fiscal sponsor:** NumFOCUS, a nonprofit organization that provides financial and administrative support.
- **Funding sources:** Donations, corporate sponsorships and institutional support.
- **Current sponsors:** Tidelift and Bodo.
- **Purpose:** Funding helps support pandas development and project infrastructure.
- **Source:** [Official pandas Sponsors page](https://pandas.pydata.org/about/sponsors.html)

## 6. Releases, Issues and Pull Requests

- **Releases:** pandas publishes versioned releases to distribute updates and improvements.
- **Issues:** The repository uses issues to track bugs and enhancement requests. Many issues are open for discussion or investigation.
- **Pull Requests:** Contributors propose code changes through pull requests, which are reviewed before being merged.
- **Activity:** The repository shows ongoing development, with recent issues and pull requests.
- **Sources:** [Releases](https://github.com/pandas-dev/pandas/releases), [Issues](https://github.com/pandas-dev/pandas/issues), [Pull Requests](https://github.com/pandas-dev/pandas/pulls)

## 7. Contribution Guide

The pandas project welcomes contributions from developers of all experience levels.

- **Finding tasks:** Beginners can look for suitable issues, including issues labeled `good first issue` and `Docs`.
- **Reporting bugs:** Bug reports and enhancement requests should be submitted through GitHub Issues.
- **Submitting changes:** Contributors use Git and GitHub, create a fork, make changes and submit a Pull Request for review.
- **Review process:** Maintainers review proposed changes before they are merged.
- **Source:** [Official pandas Contributing Guide](https://pandas.pydata.org/docs/development/contributing.html)
